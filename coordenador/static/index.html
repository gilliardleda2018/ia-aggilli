O projeto

O que é a ANI?

ANI é a sigla de Aggilli Native Intelligence, uma iniciativa brasileira que explora como desenvolver inteligência artificial com a participação de várias máquinas. A proposta é que cada participante possa contribuir com parte do treinamento e que essas contribuições ajudem a ajustar um modelo em comum.

Treinamento federado

Como as máquinas aprendem juntas?

Cada computador participante, chamado de nó, recebe os parâmetros do modelo e faz ajustes usando os exemplos disponíveis localmente. Imagine dois nós trabalhando com conjuntos de textos diferentes. Cada um faz seus próprios ajustes, e o coordenador combina as atualizações recebidas em uma nova versão para a próxima rodada.

Nessa etapa, os arquivos de treinamento ficam nos nós. O coordenador recebe as atualizações do modelo. Já as mensagens do chat são enviadas ao serviço web para gerar a resposta.
