🌍 Contribua com o treino da ANI

Qualquer máquina pode se tornar um nó da rede. Seus dados nunca saem do seu computador.

🐍

Via Python

Clone o projeto e rode o cliente de nó na sua máquina.

git clone https://github.com/gilliardleda2018/ia-aggilli.git python iniciar_no.py
📓

Via Google Colab

Use GPU gratuita do Colab para treinar a ANI sem instalar nada.

Abra o notebook no Colab e rode todas as células
🐳

Via Docker

Suba um nó em qualquer servidor com um único comando.

docker run -d \ aggilli/ani-node
